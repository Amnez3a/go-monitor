# Go-monitor

## CLI Server Monitoring Program

### Usage

*Go-monitor* retrieves server data from [servers.json](https://github.com/Amnez3a/go-monitor/blob/main/example-configuration.json). Alternatively, you can specify the path to the file using the --file flag.

```bash
./bin/go-monitor --file $USER/nameFile.json
```

If Go-monitor is run in a directory containing servers.json, it will immediately pick up the file.
